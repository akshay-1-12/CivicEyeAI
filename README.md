# CivicEye AI

**AI-Powered Citizen Civic Issue Reporting System**

## 📱 Description
CivicEye AI is a citizen-focused mobile application where users can report civic issues such as potholes, garbage, broken street lights, water leakage, and road damage by simply capturing a photo.

## ✨ Features
- One-photo complaint reporting
- AI-based issue detection
- Automatic complaint description
- Automatic GPS location capture
- Automatic department selection
- Complaint tracking
- Map-based complaint view

## 🛠️ Technology Stack
- **Android App**: Java, XML, Android Studio
- **Backend**: Python, FastAPI
- **Database**: MySQL
- **AI**: Gemini Vision API / TensorFlow Lite
